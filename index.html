FAQ

HMu에서 선택지를 4단계로 나눈 기준은 무엇이었고, 사용자가 실제로 쉽게 쓰는지는 어떻게 확인했나요?

먼저 보컬곡과 연주곡(BGM) 두 갈래로 나눴다. 그다음 대분류 → 분위기·목적 → 장르·사운드 → 세부 설정의 4단계로 선택지를 좁혀 가게 했다. 사용자 반응은 인스타그램·유튜브 채널과 음원 발매로 확인하려고 준비했다.

HMu는 1인 팀이었는데, 팀으로 일한 CUEE에서는 어떤 역할을 맡았나요?

CUEE는 시니어 쇼핑 보조 솔루션을 만든 5인 창업팀이다. 나는 팀에서 CUEE 월간 활동 보고서와 창업 지원사업 지원서를 작성했다. 팀으로 2026 GNU 개척리더스 창업 아이디어톤 경진대회 최우수상과 G-대학생 창업유망팀 동아리 챌린지 우수상을 받았다.

웹 프로토타입은 어떤 기술로 만들었고, 코드는 어디서 볼 수 있나요?

HMu의 카테고리 설정 화면을 HTML/CSS/JavaScript로 만들었다.

요즘 새로 공부하고 있는 기술이나 분야는 무엇인가요?

딥러닝·머신러닝 연구실에서 AI를 공부하고 있다. 2026년 2월부터 3월까지는 코드잇의 Python 프로그래밍 기초 과정을 수료했다.

AI 서비스 기획과 개발 중 어느 쪽에 더 가까운 엔지니어가 되고 싶나요?

개발에 더 가깝다. 목표는 소프트웨어 엔지니어다. 지금까지 HMu와 CUEE를 기획·제작했다.
